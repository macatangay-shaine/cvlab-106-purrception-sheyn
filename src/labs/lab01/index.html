    Part 1 / Understanding digital images

    What is inside an image?

    A digital image is an array. Its position identifies a pixel; its channel values describe color or intensity.

    2D

    Grayscale

    One intensity value per pixel, commonly from 0 (black) to 255 (white).

    3D

    Color

    Height × width × channels. Color images combine multiple values at each coordinate.

    BGR

    Channel order

    Python OpenCV uses blue, green, red ordering; browsers normally expose red, green, blue, alpha.

    W×H

    Resolution

    The number of horizontal and vertical pixels determines how much spatial detail can be represented.

    Equivalent Python / OpenCV
    import cv2

# Load and inspect a color image (BGR order)
img = cv2.imread("sample.jpg")
print("Shape:", img.shape)  # height, width, channels

# Convert BGR to grayscale
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)

# Inspect and change one pixel
y, x = 40, 60
print("BGR pixel:", img[y, x])
img[y, x] = [145, 91, 230]  # B, G, R

# Crop a region of interest
crop = img[50:250, 80:380]

# Resize and rotate clockwise
resized = cv2.resize(img, (640, 480))
rotated = cv2.rotate(img, cv2.ROTATE_90_CLOCKWISE)

cv2.imshow("Original", img)
cv2.imshow("Grayscale", gray)
cv2.waitKey(0)
cv2.destroyAllWindows()

    End-of-activity reflection

    01

    From seeing an image to reading its data.

    Lab 01 establishes the foundation for the experiments collected in this Computer Vision activity portfolio.

    This activity changed the way we understand a digital image: it is not only something we see, but a structured collection of numerical values that a computer can inspect, transform, and interpret.

    By working directly with pixels, we learned how image height, width, resolution, coordinates, and color channels describe visual information. Comparing browser RGBA values with Python OpenCV’s BGR order also showed why channel arrangement matters when code reads or modifies color.

    01 Representation
    Color images use multiple channel values at every coordinate, while grayscale images store one intensity value per pixel.
    02 Pixel control
    Inspecting and recoloring one pixel demonstrated that visible image changes begin with precise numerical edits.
    03 Transformation
    Grayscale conversion, cropping, resizing, and rotation showed how algorithms can change color, content, scale, and orientation.
    04 Documentation
    Recording dimensions, code, and visual evidence connected each operation to an observable and reproducible result.

    Portfolio connection. These fundamentals support the succeeding activities in edge detection, histogram analysis, feature detection, PCA, object detection, and segmentation. Understanding the pixel first makes it possible to understand the larger computer-vision systems built from it.
